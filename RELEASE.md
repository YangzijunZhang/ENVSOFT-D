# GitHub and Zenodo release

1. Create the public GitHub repository `YangzijunZhang/ENVSOFT-D` from this folder.
2. Confirm that the repository contains only the CSV inputs, source code and documentation listed in `MANIFEST.md`.
3. Create a GitHub release tagged `v1.0.0`.
4. Connect the repository to Zenodo and archive the GitHub release.
5. Add the minted DOI to the GitHub release notes, repository description, manuscript availability statement and `CITATION.cff`.

Do not insert a provisional or invented DOI. Zenodo supplies the permanent DOI when the release is archived.
