# Generated results

The scripts generate the following reproducible outputs in this directory:

- `performance/`: grid and city performance scores and reference-set summaries.
- `appendix_c/`: Table C1 and the statistics reported with Fig. C1.
- `analysis_4_2/`: 2020 regional Cropland summaries.
- `analysis_4_3/`: grid/city SDE parameters and 2010–2020 displacements.
- `sensitivity/`: publication Table D1, numeric `Table_D1_long.csv`, Table D2, threshold scores, correlations, regional results and SDEs.
- `robustness/`: replicate-level and summary metrics.
